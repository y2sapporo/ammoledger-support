# 実包等管理帳簿（AmmoLedger）Support

実包等管理帳簿をご利用いただきありがとうございます。

実包等管理帳簿は、猟銃・空気銃の所持者が、実包・火薬・雷管の譲受け・消費・残数を記録して管理するための帳簿アプリです。iPhone版・Mac版・Windows版があります。

## 主な機能

- 実包・火薬・雷管の購入・譲受・譲渡・廃棄・消費の記録
- 狩猟・有害鳥獣駆除・標的射撃の用途ごとの残数の自動計算
- 銃検査日で区切った年度ごとの年間集計
- 銃ごとの使用実績（回数・弾数）と捕獲実績の集計
- リロード（製造）と用途転用の記録
- 印刷・PDF保存・CSVの書き出しと取り込み
- バックアップと復元（iPhone版・Mac版・Windows版の間でデータを移せます）
